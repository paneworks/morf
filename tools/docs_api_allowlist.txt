# (yet) spell out. One entry per line: <name><TAB><kind>: <reason>.
#
#   undocumented:  public, and not yet in the UI or IO guide
#   internal:      not for shell authors; named here so the gate knows it
#   mirror:        another spelling of documented names (a `.*` subtree; the
#                  gate checks every name under it has its morf.* original)
#   data:          constants, not functions (a `.*` subtree; the gate checks
#                  every field under it is not a function)
#   dynamic:       a `+name` the docs mention that the generated types cannot
#                  see, because the engine serves it through __index
#
# Only mirror and data entries may be subtrees, so a new public name is never
# hidden by a wildcard. Entries nothing needs any more fail the gate; this
# list only shrinks.
